# DSA (Data Structures & Algorithms)

## 📚 Introduction
This repository contains exercises, solutions, and notes related to **Data Structures and Algorithms (DSA**. It is designed for learning, practicing, and revising fundamental concepts of DSA, ranging from basic to advanced topics.

## 📝 Contents

- **Data Structures:**  
  - Array
  - Linked List
  - Stack & Queue
  - Tree
  - Graph
  - Hash Table

- **Algorithms:**  
  - Sorting
  - Searching
  - Recursion
  - Dynamic Programming
  - Backtracking
  - Greedy Algorithms
  - Graph algorithms (DFS, BFS, Dijkstra, etc.)

- **Exercises & Solutions:**  
  - A collection of problems and solutions with detailed explanations
  - Practice tasks from beginner to advanced level

## 💡 Goals

- Master the fundamentals of Data Structures and Algorithms
- Improve problem-solving skills using DSA techniques
- Prepare for programming interviews, competitive programming, and academic exams

## 🛠 How to Use

1. Clone the repository:
    ```sh
    git clone https://github.com/FirstKhoi/DSA.git
    ```
